# Movie Ticket System (Module 3 Task 2)

This is a simple Java program that demonstrates Object-Oriented Programming concepts using a Movie Ticket system.

## Files
- `MovieTicket.java` – Represents a movie ticket with title, seat number, and price.
- `TicketOperations.java` – Handles calculations and printing receipts.
- `Main.java` – Runs the program with example data.

## How to Run
1. Compile all files:
   ```bash
   javac *.java
   ```
2. Run the main class:
   ```bash
   java Main
   ```
